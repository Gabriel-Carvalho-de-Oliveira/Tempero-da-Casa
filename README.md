Sistema de Pedidos - Gabriel Carvalho de Oliveira (SP3201007)

Tempero da Casa

- Sistema de pedidos de restaurante feito com HTML, CSS e JavaScript.

Como abrir

- Abra o arquivo `index.html` em um navegador atual. 

Funcionalidades

- Cardápio com carrossel de pratos.
- Cadastro, edição e exclusão de produtos.
- Carrinho com alteração de quantidade, remoção de itens, limpeza e total atualizado.
- Finalização do pedido com dados do cliente, retirada, consumo no local ou delivery.
- Taxa de R$ 2,50 no delivery quando o pedido contém marmita.
- Persistência do cardápio e dos pedidos finalizados no `localStorage`.

As fotos vêm de resultados da busca de imagens no Pexels. Ao cadastrar outro produto, informe uma imagem em um link HTTPS ou deixe o campo vazio para usar a imagem da categoria.
